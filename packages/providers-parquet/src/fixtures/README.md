# Test fixture

`definitions.parquet` is `data/definitions.parquet` from the Hugging Face dataset [kelkalot/every-ai-policy-ever](https://huggingface.co/datasets/kelkalot/every-ai-policy-ever), data version 1.18 (2026-10-18), licensed CC-BY-4.0 by its authors. It is used unchanged: 26 rows, ZSTD-compressed.

`shard-a.parquet`, `shard-b.parquet`, `reshard-a.parquet`, `reshard-b.parquet`
and `row-groups.parquet` are synthetic fixtures generated by
`python3 packages/providers-parquet/src/fixtures/generate-shards.py` without external
dependencies. They contain required UTF-8 fields `id`, `title`, `body`, uncompressed
PLAIN pages, and one row per row group. The reshards move all four rows between
files; the large row-group fixture makes lazy byte-range reads observable.
