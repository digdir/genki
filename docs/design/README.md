# Design

Design briefs and mock screens for work that is not built yet. Each folder holds one area: a `README.md` or `brief.md` that says what to draw and why, and the mocks when they exist.

- What is built is described by the running app and the code, not by a design file. A mock that has been built can be removed.
- New design work is drawn as Design artifacts in Claude and exported into the area's folder.
- The earlier handoffs (v1 to v5) from the standalone Claude Design project are history. That project closes on 14 December 2026 and is not the source for anything new.
