Declarative blocks

BuildingOptionalNot a block

A service owner's own block, «Uten kode», written as a template of data. The host draws it with Designsystemet components, so the theme and accessibility come from the host. No expressions, no code, no HTML, no CSS.

UI name
«Uten kode», a kind of «designelement»
Code
Render in packages/ui-blocks/src/declarative, checked by checkBlockTemplate in packages/definitions
Decision
ADR 0067

Use it when

  • A service wants a card, list or table of its own under each answer or in a panel, made from the fields genki gives a block.

Render's props

  • template: the edition's template
  • data: only the fields the template reads
  • texts: the block's texts by language
  • locale: nb, nn or en
  • props: the placed block's settings
  • state: the state the host sets
  • onEvent: what the person did, for the host to act on

Limits

  • 32 KiB as JSON, 200 nodes, 12 deep, 200 paths
  • each and table 2 deep, 10 items unless max says up to 50
  • 8 columns, 8 text parts, 20 key and value pairs, conditions 3 deep
  • At most 2000 elements once each list repeats its part as often as its max allows; past that, Render draws nothing
  • Checked in linear time: a pre-pass with an explicit stack refuses an input over the limits before the schema reads it

Elements

  • stack, row: a vertical or horizontal group
  • card, details: Card, Details
  • heading (levels 2 to 4), paragraph: Heading, Paragraph
  • list: List; an each in it gives one item per element
  • link: Link, to an https address, a page of the service or a field of type url; checked again when drawn
  • button: Button, sending one of the block's declared events: ask, open-document, set-filter, open-page or notify
  • tag, alert, divider: Tag, Alert, Divider
  • icon: an Aksel icon from a fixed list, hidden from screen readers without a label
  • table: Table, one row per element of a list
  • keyValue: a description list
  • each, if: repeat over a list, or draw one branch

Texts and data

  • Every word is a key in the block's texts, with bokmål required. A literal is at most 8 characters with no letters, such as ", ".
  • A binding reads a field of genki's field list, such as sources.title through an each, a declared prop, or nothing. The host gives the block only the fields its template reads.
  • Data is always written as text, never as HTML.

Styling

  • --genai-declarative-font-family, --genai-declarative-gap-sm, --genai-declarative-gap-md, --genai-declarative-gap-lg, --genai-declarative-subtle-color, --genai-declarative-key-weight and --genai-declarative-icon-size
