Repository skills for Claude Code are in `.claude/skills`: `review-change` for the review CI runs, `security-sweep` for the weekly whole-repository security sweep, `sweep-triage` for a maintainer to triage its findings, `adr` for architecture decisions, `writing-pr-descriptions` for pull request text, `design-system-check` to check that frontend code uses Designsystemet's components and tokens, and `genki-admin` for working on services in a running genki.
